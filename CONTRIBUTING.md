# Contributing to Gurita for Codex

This repository is the Codex distribution of [Gurita](https://github.com/uHappyLogic/gurita), and it takes no contributions directly. Every file on `main` is rendered from the sources of [uHappyLogic/gurita](https://github.com/uHappyLogic/gurita) by its host build and published verbatim by each Gurita release, so a change made here — a pull request against this repository included — would be overwritten by the next release. Issues, Discussions, projects, and the wiki are disabled in this repository on purpose.

Everything goes to the root repository instead:

- **Bug reports and feature requests** — open an [issue at uHappyLogic/gurita](https://github.com/uHappyLogic/gurita/issues/new/choose), using its bug or feature form.
- **Changes and pull requests** — read the root repository's [contributing guide](https://github.com/uHappyLogic/gurita/blob/main/CONTRIBUTING.md), which describes how a change is proposed, run as a mission in a fork of the root repository, and submitted as a pull request there. The plugin's sources live under `core/` in that repository; this tree is a build of them.
- **Security vulnerabilities** — report them privately through the root repository's [Report a vulnerability](https://github.com/uHappyLogic/gurita/security/advisories/new) form, never as an issue or a pull request; its [security policy](https://github.com/uHappyLogic/gurita/blob/main/SECURITY.md) has the details.
- **Questions** — ask in the root repository's [Discussions](https://github.com/uHappyLogic/gurita/discussions/new?category=q-a).
